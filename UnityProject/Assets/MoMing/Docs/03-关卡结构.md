# 关卡结构

---

## 1. 房间拼接模式

采用类似《小小梦魇》的房间拼接模式：

- 每个关卡由 **5 间房间** 线性串联组成
- 每间房间是一个独立的解谜/生存单元
- 玩家从入口进入，解开当前房间谜题后通过出口进入下一间
- 房间之间通过门/通道连接

### 1.1 房间类型

| 类型 | 特征 | 怪物 | 焦虑 |
|------|------|------|------|
| **安全解谜房** | 纯解谜，无生存压力 | 无（进入即消失） | 仅在分离时增长 |
| **危险巡逻房** | 怪物巡逻，需躲避同时解谜 | 有，固定路线巡逻 | 分离时增长更快 |

### 1.2 房间序列模式

每关 5 间房按以下模式交替：

```
房间1（安全/教学）→ 房间2（危险）→ 房间3（安全）→ 房间4（危险）→ 房间5（安全/结算）
```

## 2. 两版关卡总览

### 2.1 地上 · 诊疗病区

| 项目 | 说明 |
|------|------|
| 空间结构 | 线性推进为主 |
| 谜题风格 | 偏静态空间解锁 |
| 怪物行为 | 固定路线巡逻 |
| 整体节奏 | 平缓，侧重基础机制组合运用 |

### 2.2 地下 · 收容监区

| 项目 | 说明 |
|------|------|
| 空间结构 | 环形/折返为主 |
| 谜题风格 | 偏时序配合与动态风险 |
| 怪物行为 | 巡逻逻辑更复杂 |
| 整体节奏 | 焦虑压力更强，侧重双人切换与时机把控 |

---

## 3. 对应房间玩法差异对照表

| 房间序号 | 地上 · 诊疗病区 | 地下 · 收容监区 | 逻辑差异 |
|---------|----------------|----------------|---------|
| 1号房 | 抱团推障 + 单人拾取道具开门 | 开局直接分离 + 双开关同步触发 | 地上先协同后分离，地下先分离后汇合 |
| 2号房 | 单直线走廊 + 交替掩护突进 | 回字形环形 + 双向绕路同步踩点 | 地上直线交替，地下环形绕圈 |
| 3号房 | 全程抱团 + 连续推重物压踏板 | 强制分离 + 时序配合穿门 | 地上纯协同，地下纯分离时序 |
| 4号房 | U型静态回廊 + 逐段突破开门 | 直线动态廊道 + 卡移动障碍时机 | 地上静态分段推进，地下动态障碍穿越 |
| 5号房 | 先堵门防御 + 单点踏板通关 | 多点位跑图 + 连锁解锁踏板通关 | 地上防御式单点触发，地下探索式时序解锁 |
