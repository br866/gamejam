# 08 音乐系统（现状说明）

> 一句话：**音效/策划只改一张 CSV 表,程序按游戏状态自动播背景音乐/氛围。** 全组 Unity 2022.3,协程实现,无新版专属 API。

---

## 1. 这套是干什么的

背景音乐(BGM)和氛围音(ambience)的播放系统。特点:

- **数据驱动**:所有曲子登记在一张 CSV 表里,加/换曲不用改代码。
- **按状态自动切歌**:根据"两人在一起 / 分离 / 焦虑值高低"自动切到对应的曲子(对应策划的距离/焦虑玩法)。
- **交叉淡入淡出**:切歌平滑过渡,不是硬切。
- 只管**背景音乐/氛围层**;一次性音效(脚步、开关门等)不走这套。

---

## 2. 涉及的文件

| 文件 | 作用 |
|------|------|
| `Scripts/Audio/MusicManager.cs` | 单例管理器:读表、点播、交叉淡变、按状态自动切歌 |
| `Scripts/Audio/MusicTable.cs` | 把 CSV 解析成「Id → 配置」的数据类 |
| `Resources/MoMingConfig/music_table.csv` | **要填的就是这张表** |
| `Resources/Audio/`（待放音频） | 音频文件目录,文件名要和表里 ClipName 一致 |

> CSV 和音频必须放在 `Resources` 下,运行时才能加载。

## 4. 怎么用

1. 场景里 `GameObject → Create Empty`,命名 `MusicManager`,挂 `MusicManager` 脚本。
2. 音频文件(.wav/.mp3/.ogg)放进 `Assets/MoMing/Resources/Audio/`,文件名 = 表里的 `ClipName`。
3. 运行。默认"自动模式"已开,进场先播 `bgm_puzzle`,两人分开/焦虑升高会自动切曲。

AudioSource 由脚本自动创建,不用手动加。

---

## 5. 表格怎么填（`music_table.csv`）

| 列 | 含义 |
|----|------|
| Id | 唯一键,程序用它点播,如 `bgm_puzzle` |
| ClipName | Resources/Audio 下的音频文件名(不带扩展名) |
| Volume | 音量 0~1 |
| Loop | 是否循环 |
| FadeIn / FadeOut | 淡入/淡出秒数 |
| Note | 备注(程序不读) |

规则:表头列名别改;`#` 开头是注释;字段里别用英文逗号(中文逗号可以);可用 Excel 打开另存为 CSV。

---

## 6. 自动切歌逻辑（`MusicManager` Inspector 可调）

| 状态 | 播放 | 对应字段 |
|------|------|---------|
| 在一起、焦虑低 | 基础 OST | `Id Together` |
| 刚分离、焦虑还低 | 过渡桥段 | `Id Separated Transition` |
| 分离久、焦虑≥0.35 | 分离 OST | `Id Separated` |
| 焦虑≥0.6 | 焦虑/心跳层 | `Id Anxiety` |

阈值和每档对应的 Id 都能在 Inspector 改,换曲不用改代码。读的状态来自 `PlayerManager.IsTogether` 和 `GameManager.GetAnxietyNormalized()`。

---

## 7. 代码里手动控制（剧情演出等）

```csharp
MusicManager.Instance.PlayMusic("amb_underground");   // 点播
MusicManager.Instance.PlayMusic("bgm_anxiety", 3f);    // 3秒淡变
MusicManager.Instance.StopMusic();                     // 停止
MusicManager.Instance.SetAutoDrive(false);             // 关掉自动、手动接管
```
