# 08 音乐系统（填表即可）

> 目标：音效/策划只负责**填一张表**（CSV），程序在合适的时机自动播放。
> 实现：`MusicTable`（解析 CSV）+ `MusicManager`（单例，交叉淡入淡出、按游戏状态自动切歌）。
> 全组统一 Unity 2022.3：淡变用协程，**不用 async/await**，只用 2022.3 原生 API。

---

## 1. 新增了哪些文件

| 文件 | 作用 |
|------|------|
| `Scripts/Audio/MusicTable.cs` | 数据类：把 CSV 解析成「Id → 音乐配置」的表 |
| `Scripts/Audio/MusicManager.cs` | 单例管理器：点播、交叉淡变、按状态自动切歌 |
| `Resources/MoMingConfig/music_table.csv` | 音乐表（你要填的就是这个） |
| `Resources/Audio/`（待你放音频） | 音频文件目录，文件名要和表里的 ClipName 一致 |

> ⚠️ CSV 和音频都必须放在 **`Resources`** 文件夹下，程序才能在运行时用 `Resources.Load` 读到。

---

## 2. 表格长什么样

`music_table.csv` 每一行就是一条音乐配置：

| 列名 | 含义 | 例子 |
|------|------|------|
| Id | 唯一键，程序用它点播 | `bgm_puzzle` |
| ClipName | 音频文件名（放在 Resources/Audio 下，不带扩展名） | `bgm_puzzle` |
| Volume | 音量 0~1 | `0.7` |
| Loop | 是否循环 | `true` |
| FadeIn | 淡入秒数 | `2` |
| FadeOut | 淡出秒数 | `2` |
| Note | 备注（给人看，程序不读） | `安全解谜房底噪` |

**填表规则**：
- 第一行表头的**列名别改**，顺序可以调。
- `#` 开头的行是注释，会被跳过。
- 字段里**不要出现英文逗号 `,`**（它是分隔符）。中文逗号没问题。
- 可以直接用 Excel 打开这个 CSV 编辑，另存时仍存成「CSV（逗号分隔）」即可。

---

## 3. 音频文件放哪

把音频（.wav / .mp3 / .ogg）放进：

```
Assets/MoMing/Resources/Audio/
```

文件名要和 CSV 里的 `ClipName` **完全一致**（不带扩展名）。
例如表里写 `bgm_puzzle`，就放一个 `bgm_puzzle.wav`。

> 原型阶段还没有音频文件？没关系。表里可以先填好，程序找不到文件会**静默跳过**、不报错。

---

## 4. 怎么用（编辑器接线，30 秒）

1. 在场景里 `GameObject → Create Empty`，命名 `MusicManager`。
2. 挂上 `MusicManager` 脚本。
3. 运行。默认「自动模式」已开，进场会先播 `bgm_puzzle`。

就这样。AudioSource 由脚本自动创建，不用手动加。

---

## 5. 程序在“合适的时机”怎么切歌

`MusicManager` 勾选了 **Auto Drive By Game State** 后，每帧读两处状态自动选曲：

- `PlayerManager.IsTogether`：两人是否在一起
- `GameManager.GetAnxietyNormalized()`：焦虑值 0~1

选曲逻辑（对应文档里「距离越远→过渡→分离」的设计）：

| 状态 | 播放 | 对应 Inspector 字段 |
|------|------|--------------------|
| 在一起、焦虑低 | 基础 OST | `Id Together` = `bgm_puzzle` |
| 刚分离、焦虑还低 | 过渡桥段(subtle) | `Id Separated Transition` |
| 分离持续、焦虑升高(≥0.35) | 分离状态 OST | `Id Separated` |
| 焦虑很高(≥0.6) | 焦虑氛围/心跳层 | `Id Anxiety` |

阈值 `Separated Anxiety Threshold` / `Anxiety Layer Threshold` 都能在 Inspector 调。
每一档对应的 Id 也能改成表里的任意一行——**换曲不用改代码，改字段就行。**

## 6. 代码里手动控制（剧情演出等场合）

```csharp
// 点播某一行（Id 来自 CSV）
MusicManager.Instance.PlayMusic("amb_underground");

// 指定 3 秒淡变
MusicManager.Instance.PlayMusic("bgm_anxiety", 3f);

// 停止（淡出）
MusicManager.Instance.StopMusic();

// 想手动接管时，先关掉自动模式
MusicManager.Instance.SetAutoDrive(false);
```

## 7. Unity 2022.3 兼容性（别改成更高版本才有的 API）

全组都在 2022.3。以下是 2022.3 的正确写法，别改成新版 API，否则会编译报错：

| 不要改成 | 保留用 | 原因 |
|----------|--------|------|
| `async / await` / `Awaitable` | 协程 `IEnumerator` | Awaitable 是更高版本才有的 API，2022.3 没有 |
| `FindFirstObjectByType` | `FindObjectOfType` | 2022.3 用 `FindObjectOfType` |

淡变用了 `Time.unscaledDeltaTime`，这样即使游戏暂停（`Time.timeScale = 0`）音乐仍能淡入淡出。
