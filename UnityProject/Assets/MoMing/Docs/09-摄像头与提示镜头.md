# 09 摄像头系统（现状说明）

> 一句话:第三人称跟随摄像机,**向前看的低角度视角**,自动跟随当前角色,带防穿墙、遮挡透视、暂停冻结。
> 脚本:`Scripts/Core/CameraFollow.cs`(挂在场景/预制体的摄像机上)。全组 Unity 2022.3,协程实现,无新版专属 API。

---

## 1. 这台摄像机现在的行为

- **跟随当前角色**;联动模式(Q)下跟随两人中点。
- **向前看的视角**(低俯角,像截图那种斜后方,不是居高临下的俯视)。
- **鼠标默认不转视角**(避免走位方向错乱)。
- **防穿墙**:贴墙角时镜头自动拉近,不会穿出建筑看到外面。
- **遮挡透视**:挡在镜头和角色之间的物体(含其子物体)自动隐藏。
- **开局不摆动**:进 Play 第一帧直接就位,不从编辑器摆放位置滑过去。
- **暂停冻结**:菜单打开(`timeScale=0`)时镜头也锁住,不响应鼠标。

---

## 2. 当前参数（默认值）

| 参数 | 值 | 说明 |
|------|----|------|
| `distance` | 8 | 镜头与角色的距离,越小越近 |
| `angle` | 20 | **俯角**。0=纯平视,越大越居高临下。20≈向前看略带俯视 |
| `followSpeed` | 8 | 跟随平滑速度 |
| `enableMouseRotation` | false | 鼠标是否能转视角(默认关) |
| `enableObstructionHide` | true | 遮挡物是否自动隐藏 |
| `enableCameraCollision` | true | 是否防穿墙(贴墙压缩镜头) |
| `collisionBuffer` | 0.3 | 镜头停在墙前留的缝 |
| `minCollisionDistance` | 1.5 | 压缩时离角色的最近距离(防贴脸) |

> **想改视角高低就调 `angle`**:想更平往前看→调小(10~15);想更俯视→调大(45~70)。

---

## 3. 参数存在哪 / 改哪里生效（重要）

不同场景的摄像机来源不同,改的地方也不同:

- **`superbreadman 1` 等用 `PlayerSystem.prefab` 的场景**:摄像机在预制体里 → 改 `Prefabs/PlayerSystem.prefab` 的 CameraFollow,所有用它的场景一起变。
- **`Test_MoMing` / `Test_Level1` 等测试场景**:摄像机(名为 `MainCamera`)直接摆在场景里,且**没序列化 angle/distance**,会回退用**脚本默认值**。所以改 `CameraFollow.cs` 里的默认值(`distance=8f`/`angle=20f`)对这些场景生效。
- 单独在某个场景里选中 `MainCamera` → Inspector 改,只影响那个场景。

> 目前预制体和脚本默认值已统一为 **angle 20 / distance 8 / 鼠标转向关**。

---

## 4. 这一版做了哪些改动（相对最初）

| 改动 | 说明 |
|------|------|
| 视角改成向前看 | `angle` 从 55 一路调到 **20**,不再居高临下 |
| 关掉鼠标转视角 | `enableMouseRotation` 默认 false |
| 新增**防穿墙** | 贴墙角时镜头拉到墙前,不穿出建筑(`enableCameraCollision`) |
| 遮挡隐藏**连子物体** | 修了导入 FBX 模型(碰撞体在父、网格在子)挡视线的问题 |
| 开局不摆动 | 第一帧瞬间就位,不再从编辑器位置滑动 |
| 暂停冻结镜头 | `timeScale=0` 时 `LateUpdate` 直接返回 |

---

## 5. 怎么调（新手）

1. Hierarchy 里选中摄像机(测试场景叫 `MainCamera`)。
2. Inspector 找 **Camera Follow** 组件。
3. 常用就三个:`Angle`(视角高低)、`Distance`(远近)、`Enable Mouse Rotation`(要不要鼠标转视角)。
4. 想所有场景统一,就改 `Prefabs/PlayerSystem.prefab`(而不是单个场景)。

## 6. 提示镜头（PlayHint）—— 已实现但**当前未启用**

代码里有一套"提示镜头":玩家走进某区域,镜头飞去看某个机关、停一下再飞回。相关:`CameraFollow.PlayHint()`、`Scripts/Environment/HintTrigger.cs`、`Checkpoint.hintTarget`。

**现状:场景里没摆任何 HintTrigger,也没给存档点设 hintTarget,所以这套目前完全不触发、不影响游戏。** 属于"留着备用"。若以后想用:给空物体加 Box Collider(Is Trigger)+ `HintTrigger` + 拖入 Focus Target,并确保角色 Tag=`Player`。详见 `11-提示镜头接线TODO.md`。

> 关于 Cinemachine:**不用**。现有手写方案已满足需求,少一个依赖,全组同版本也省事。

## 7. Unity 2022.3 兼容性

全组 2022.3。以下是 2022.3 正确写法,别改成更高版本才有的 API(否则编译报错):

| 别改成 | 用 |
|--------|----|
| `async/await` / `Awaitable` | 协程 `IEnumerator` |
| `rb.linearVelocity` | `rb.velocity` |
| `FindFirstObjectByType` | `FindObjectOfType` |

在 2022.3 上这些都是当前 API,不会有过时警告。
