# 音效需求清单

> **原型阶段不导入任何音频文件。** 脚本中预留 `[SerializeField] private AudioClip` 字段，Inspector 中暂不赋值（null 时静默跳过）。本文件汇总所有已接入代码的音频字段及尚未实现的需求，供后续批量制作音频并赋值时参考。

---

## 1. 音频调用约定

- 所有音频播放统一走 `PlayAudio(AudioClip clip)` 包装方法，`clip == null` 时静默跳过，不报错
- 字段统一标记 `[SerializeField] private`，通过 Inspector 后续赋值
- 不在代码中硬编码加载音频路径
- 音频文件放入 `Assets/MoMing/Audio/`，建议按 `SFX/` 和 `BGM/` 子分类

```csharp
void PlayAudio(AudioClip clip)
{
    if (clip != null && audioSource != null)
        audioSource.PlayOneShot(clip);
}
```

## 2. 音量控制系统（已实现）

| 脚本 | 位置 | 说明 |
|------|------|------|
| `SettingsManager.cs` | `Scripts/UI/` | 挂在 SettingsPanel 根节点，OnEnable/OnDisable 管理滑块监听器。音乐/音效音量通过 PlayerPrefs 持久化，跨场景生效。 |

**当前实现（原型阶段）：**
- `MusicVolume` / `SfxVolume` 静态字段，通过 `PlayerPrefs` 持久化
- `ApplyVolumes()` 使用 `AudioListener.volume = (musicVolume + sfxVolume) * 0.5f`（简易平均）

**待改进：**
- 接入 `AudioMixer`，将 BGM 和 SFX 分到独立 Group，实现独立音量控制
- 当前 `AudioListener.volume` 方案无法分别控制 BGM 和 SFX

## 7. 音频文件放置与赋值指南

1. 将音频文件放入 `Assets/MoMing/Audio/SFX/`（音效）或 `Assets/MoMing/Audio/BGM/`（背景音乐）
2. 在对应 GameObject 上确保已挂载 `AudioSource` 组件（各脚本在 `Awake()` 中通过 `GetComponent<AudioSource>()` 获取）
3. 在 Inspector 中将 AudioClip 拖入对应的 `[SerializeField] private AudioClip` 字段
4. SFX 的 AudioSource 建议 `playOnAwake=false, loop=false`；BGM 的 AudioSource 建议 `playOnAwake=true, loop=true`
5. BGM 接入后需将 `SettingsManager.ApplyVolumes()` 升级为 AudioMixer 方案，实现 BGM/SFX 独立音量控制
