## Test_Level1（教学关 · 3 房）

> 线性推进，无怪物，侧重基础机制教学。

### Room1：推箱清障
- **类型**：安全解谜房
- **考察能力**：联动推箱子(Q)、人触发开关(F)
- **解谜流程**：
  1. 双人按 Q 进入联动模式
  2. 联动推动 HeavyBox 清出通路
  3. 人分离前往 Switch1，按 F 激活 → Gate1 开启
- **房间范围**：X 0~12, Z -5~5

### Room2：道具拾取
- **类型**：安全解谜房
- **考察能力**：人拾取道具(E)、道具触发开关(F)
- **解谜流程**：
  1. 人分离进入侧边区域拾取 Key（按 E）
  2. 携带 Key 前往 Switch2（需道具），按 F 激活 → Gate2 开启
- **房间范围**：X 14~26, Z -5~5

### Room3：双人踏板
- **类型**：安全结算房
- **考察能力**：双人压重踏板（PressurePlate, requiredCount=2）
- **解谜流程**：
  1. 双人同时踩上两个 PressurePlate（需联动模式或分别控制）
  2. 两块踏板同时被踩 → Gate3 开启 → 通关
- **房间范围**：X 28~40, Z -5~5

## Test_Level2（危险走廊 · 4 房）

> 引入怪物巡逻机制，考验狗的脚印感知与疾跑能力。

### Room1：分离开关
- **类型**：安全解谜房
- **考察能力**：人触发开关(F) + 狗踩踏板(PressurePlate, requiredCount=1)
- **解谜流程**：
  1. 隔墙强制分离：人走左侧，狗走右侧
  2. 人在 SwitchL 按 F 激活 + 狗踩上 PlateR → Gate1 开启
- **房间范围**：X 0~12, Z -5~5

### Room2：走廊巡逻
- **类型**：危险巡逻房
- **考察能力**：狗看脚印(FootprintMarker)、狗疾跑(LeftShift)、人触发开关(F)
- **解谜流程**：
  1. 切换到狗，看到地面红色脚印预判怪物巡逻路线
  2. 狗疾跑穿过走廊（怪物在房间内往返巡逻）
  3. 狗到达 Switch2，按 F 激活 → Gate2 开启
  4. 人跟进穿过走廊
- **房间范围**：X 14~30, Z -4~4（窄走廊）
- **怪物**：1 个怪物，2 个 waypoint 往返巡逻

### Room3：闸阀守门
- **类型**：安全解谜房
- **考察能力**：人按住闸阀(HoldSwitch, 持续按 F)
- **解谜流程**：
  1. 人在 Valve 旁按住 F 键，Gate3 持续开启
  2. 狗穿过 Gate3 到达另一侧
  3. 人松开 F，Gate3 关闭，两人分别在内墙两侧
  4. 继续推进到 Room4
- **房间范围**：X 32~44, Z -5~5

### Room4：追击逃脱
- **类型**：危险巡逻房
- **考察能力**：联动推箱封路(Q) + 双人压重踏板
- **解谜流程**：
  1. 联动推动 Box 封住入口（防御怪物追击）
  2. 双人同时踩上两个 PressurePlate → 通关
- **房间范围**：X 46~58, Z -5~5
- **怪物**：1 个怪物，2 个 waypoint 往返巡逻

## Test_Level3（综合挑战 · 4 房）

> 全部能力综合运用，节奏紧凑。

### Room1：推箱 + 拾取
- **类型**：安全解谜房
- **考察能力**：联动推箱子(Q)、人拾取道具(E)、道具触发开关(F)
- **解谜流程**：
  1. 联动推动 Box 清出通往 Key 的路径
  2. 人分离拾取 Key（按 E）
  3. 携带 Key 前往 Switch1（需道具），按 F 激活 → Gate1 开启
- **房间范围**：X 0~14, Z -5~5

### Room2：环形巡逻
- **类型**：危险巡逻房
- **考察能力**：狗看脚印、狗疾跑、双人压重踏板
- **解谜流程**：
  1. 房间中央有方形障碍物，形成环形通道
  2. 怪物沿 4 个 waypoint 环形巡逻
  3. 狗看脚印预判路线，疾跑绕过怪物
  4. 双人同时踩上对角的两个 PressurePlate → Gate2 开启
- **房间范围**：X 16~30, Z -7~7
- **怪物**：1 个怪物，4 个 waypoint 环形巡逻

### Room3：时序配合
- **类型**：安全解谜房
- **考察能力**：人按住闸阀(HoldSwitch) + 狗疾跑穿越
- **解谜流程**：
  1. 内墙将房间分为左右两半，Gate3 是唯一通道
  2. 人在 Valve 旁按住 F，Gate3 开启
  3. 狗疾跑穿过 Gate3 到达另一侧
  4. 人松开 F 继续推进
- **房间范围**：X 32~46, Z -5~5

### Room4：防御通关
- **类型**：安全结算房
- **考察能力**：联动推箱封路(Q) + 双人压重踏板
- **解谜流程**：
  1. 联动推动 Box 封住西侧入口
  2. 双人同时踩上两个 PressurePlate → Gate4 开启 → 通关
- **房间范围**：X 48~60, Z -5~5
