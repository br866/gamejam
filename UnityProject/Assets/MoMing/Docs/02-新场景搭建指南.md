# 新场景搭建指南

从零创建一个可测试的游戏场景，使用已有预制体快速搭建。

---

## 1. 创建场景

1. Unity 菜单 `File → New Scene`，选择 `Basic (URP)` 模板
2. 保存到 `Assets/MoMing/Scenes/Game/` 或 `Assets/MoMing/Scenes/Test/` 下
3. 命名遵循 `01-项目规范.md` 中的规则：测试场景 `Test_名称.unity`，关卡场景 `Level_XX_名称.unity`

> 新场景默认包含 Main Camera 和 Directional Light。**删除自带的 Main Camera**，PlayerSystem 内含专用摄像机。

---

## 2. 放置 PlayerSystem（一键搞定）

**预制体路径**：`Assets/MoMing/Prefabs/PlayerSystem.prefab`

将 `PlayerSystem.prefab` 拖入场景根级。这一个预制体包含玩家控制所需的全部内容：

```
PlayerSystem
├── Human          — 人角色（PlayerController, Rigidbody, Collider）
├── Dog            — 狗角色（PlayerController, Rigidbody, Collider）
├── MainCamera     — 摄像机（CameraFollow）
├── GameManager    — 焦虑值/关卡重置/场景切换
├── PlayerManager  — 角色切换/联动模式/距离判定
├── Canvas         — 焦虑条/黑暗遮罩/聚光灯遮罩/操作说明
└── EventSystem    — UI 事件系统
```

### 2.1 所有内部引用已预连

以下引用在预制体中已全部连好，**拖入即可用，无需手动赋值**：

| 对象 | 字段 | 已指向 |
|------|------|--------|
| GameManager | `humanPlayer` | Human |
| GameManager | `dogPlayer` | Dog |
| GameManager | `spotlightMask` | Canvas/SpotlightMask |
| GameManager | `darknessOverlay` | Canvas/DarknessOverlay |
| GameManager | `anxietyBarFill` | Canvas/AnxietyBarPanel/AnxietyBarFill |
| PlayerManager | `human` | Human (PlayerController) |
| PlayerManager | `dog` | Dog (PlayerController) |

### 2.2 按需调整的字段

拖入场景后，展开 `PlayerSystem → GameManager`，根据关卡需求调整：

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `levelStartHuman` | 人角色出生坐标 | `(0, 1, -3)` |
| `levelStartDog` | 狗角色出生坐标 | `(1.5, 1, -3)` |
| `nextSceneName` | 通关后加载的下一个场景名 | `""`（空=不跳转） |
| `anxietyIncreaseRate` | 分离时焦虑上升速度 | `10` |

> **提示**：如果角色出生位置不在 `(0,1,-3)`，同时修改场景中 Human/Dog 的 Transform 和 GameManager 的 `levelStartHuman`/`levelStartDog`，确保一致。

### 2.3 摄像机设置

展开 `PlayerSystem → MainCamera`，CameraFollow 组件提供两个核心参数：

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `distance` | 摄像机与目标的总距离（越大越远） | `15` |
| `angle` | 俯视角（0=平视，90=正俯视） | `55` |
| `followSpeed` | 跟随平滑速度 | `8` |

> 调大 `distance` 拉远摄像机，调大 `angle` 增加俯视角度。两者独立控制。

## 3. 搭建房间结构（Primitive）

用 Unity Primitive 搭建房间墙体、地板、天花板。以下为一个 10×10 标准房间的示例参数：

| 物件名 | Primitive | Position | Scale |
|--------|-----------|----------|-------|
| `RoomX_Floor` | Plane | `(cx, 0, cz)` | `(1, 1, 1)` |
| `RoomX_WallN` | Cube | `(cx, 0.5, cz+5)` | `(10, 1, 0.3)` |
| `RoomX_WallS` | Cube | `(cx, 0.5, cz-5)` | `(10, 1, 0.3)` |
| `RoomX_WallW` | Cube | `(cx-5, 0.5, cz)` | `(0.3, 1, 10)` |
| `RoomX_WallE_up` | Cube | `(cx+5, 0.5, cz+3)` | `(0.3, 1, 4)` |
| `RoomX_WallE_Lo` | Cube | `(cx+5, 0.5, cz-3)` | `(0.3, 1, 4)` |

> `cx, cz` 为房间中心坐标。东侧墙留 2 格缺口作为门洞，供 Gate 预制体填充。

### 多房间连接

- 相邻房间之间用 `Bridge`（Cube, scale `(0.2, 1, 1)`）连接地面
- 门洞处放 Gate 预制体（见第 4 节）

## 4. 放置机关预制体

所有机关预制体位于 `Assets/MoMing/Prefabs/Mechanics/`。

### 4.1 门 / 栅栏 — Gate.prefab

| 步骤 | 操作 |
|------|------|
| 拖入场景 | 放在门洞处（如 `(10, 1.5, 0)`），Scale `(0.3, 3, 4)` |
| 无需手动引用 | GateController 不引用其他对象，被开关/踏板引用 |

### 4.2 开关 — PuzzleSwitch.prefab

| 步骤 | 操作 |
|------|------|
| 拖入场景 | 放在房间内合适位置 |
| **必填引用** | `linkedGate` → 拖入场景中对应的 Gate 对象 |
| 已保留引用 | `indicatorRenderer` / `inactiveMaterial` / `activeMaterial` 无需设置 |
| 可选 | `requiresItem` 勾选则需人角色持有道具才能激活 |

### 4.3 压力踏板 — PressurePlate.prefab

| 步骤 | 操作 |
|------|------|
| 拖入场景 | 放在地面上（Y≈0.05），Scale `(2, 0.1, 2)` |
| **必填引用** | `linkedGate` → 拖入场景中对应的 Gate 对象 |
| 检查设置 | `requiredCount` 默认 `2`（需 2 个不同对象踩过） |

### 4.4 持续按住开关 — HoldSwitch.prefab

| 步骤 | 操作 |
|------|------|
| 拖入场景 | 放在房间内合适位置 |
| **必填引用** | `linkedGate` → 拖入场景中对应的 Gate 对象 |
| 检查设置 | `permanentAfterHold` = false 表示松开就关闭；true 表示按住到时间后永久开启 |
| 检查设置 | `holdTimeRequired` = 0 表示按住即激活；>0 表示需按住N秒 |

### 4.5 脚印标记 — FootprintMarker.prefab

| 步骤 | 操作 |
|------|------|
| 拖入场景 | 放在需要脚印提示的位置（如通道、线索处） |
| 无需手动引用 | 自动监听 PlayerManager，操作狗时自动显示 |

### 4.6 关卡出口 — LevelExit.prefab

| 步骤 | 操作 |
|------|------|
| 拖入场景 | 放在最后一间房出口处 |
| 确认 Tag | 对象 Tag 应为 `LevelExit`（已保存在预制体中） |
| 运行效果 | 玩家触碰后触发 `GameManager.OnLevelComplete()`，加载 `nextSceneName` |

## 5. 放置道具预制体

道具预制体位于 `Assets/MoMing/Prefabs/Items/`。

### 5.1 可推动箱子 — PushableBox.prefab

| 步骤 | 操作 |
|------|------|
| 拖入场景 | 放在房间内合适位置（Scale 默认 `(1.5, 1, 1.5)`） |
| 无需手动引用 | PushableBox 无外部引用，联动模式(Q)下靠近即可推 |

### 5.2 可拾取道具 — PickupItem.prefab

| 步骤 | 操作 |
|------|------|
| 拖入场景 | 放在房间内合适位置 |
| 无需手动引用 | 人角色靠近按 E 拾取，再按 E 丢弃 |

## 6. 放置敌人（可选）

| 预制体 | 路径 |
|--------|------|
| Monster | `Assets/MoMing/Prefabs/Enemies/Monster.prefab` |

### 6.1 操作步骤

1. 将 `Monster.prefab` 拖入需要怪物的房间
2. 在场景中创建 2-3 个空 GameObject 作为巡逻点（命名如 `WP1`, `WP2`）
3. 选中 Monster，在 `MonsterPatrol` 组件中设置：

| 字段 | 说明 |
|------|------|
| `waypoints` | 将巡逻点 GameObject 拖入数组 |
| `roomCenter` | 怪物活动房间中心坐标 |
| `roomSize` | 房间大小（默认 `(16, 10, 10)`），怪物不会超出此范围 |
| `patrolSpeed` | 巡逻速度（默认 2.5） |
| `chaseSpeed` | 追击速度（默认 4.5） |
| `detectionRange` | 检测范围（默认 8） |
| `fieldOfView` | 视野角度（默认 60°） |
| `hearingRadius` | 听觉半径（默认 4） |
| `catchRadius` | 抓捕半径（默认 1.2） |

> **重要**：`waypoints` 是场景级引用，放入场景后必须重新赋值。

## 8. 搭建顺序速查

```
1. 新建场景，删除自带 Main Camera
2. 拖入 PlayerSystem.prefab（角色+摄像机+UI+管理器，一步到位）
3. 搭建房间 Primitive（地板/墙壁/桥）
4. 拖入 Gate.prefab 放门洞
5. 拖入机关（PuzzleSwitch/PressurePlate/HoldSwitch）
6. 拖入道具（PushableBox/PickupItem）
7. （可选）拖入 Monster.prefab + 创建巡逻点
8. 拖入 FootprintMarker.prefab
9. 拖入 LevelExit.prefab 放出口
─── 以下为连线 ───
10. 每个开关/踏板: linkedGate → 对应 Gate
11. Monster: waypoints / roomCenter / roomSize
12. GameManager: 按需调整 levelStartHuman / levelStartDog / nextSceneName
```

## 9. 测试运行

### 9.1 Play Mode 检查清单

点击 Unity 编辑器顶部 ▶ 播放按钮，逐项确认：

| # | 检查项 | 预期结果 |
|---|--------|---------|
| 1 | 场景不报错 | Console 无红色错误 |
| 2 | 人角色可移动 | WASD 控制人角色移动 |
| 3 | 角色切换 | Tab 键在人/狗之间切换 |
| 4 | 跳跃正常 | Space 键可跳 |
| 5 | 摄像机跟随 | 摄像机跟随活跃角色 |
| 6 | 开关交互 | 人角色靠近 PuzzleSwitch 按 F，门打开 |
| 7 | 踏板触发 | 踩过 PressurePlate 后达到 requiredCount，门打开 |
| 8 | 推箱子 | Q 进入联动模式后可推 PushableBox |
| 9 | 拾取道具 | 人角色靠近 PickupItem 按 E 拾取，再按 E 丢弃 |
| 10 | 焦虑系统 | 分离后焦虑条上升；重聚后下降 |
| 11 | 关卡重置 | 焦虑满后角色回到出生点 |
| 12 | 关卡完成 | 触碰 LevelExit 后切换场景（如设置了 nextSceneName） |
| 13 | 怪物（如有） | 在房间内巡逻，发现玩家追击，抓住玩家触发重置 |

### 9.2 常见问题排查

| 问题 | 原因 | 解决 |
|------|------|------|
| 角色不动 | PlayerSystem 未正确拖入 | 确认 PlayerSystem 是预制体实例，GameManager 引用不为 null |
| 摄像机不动 | 同上 | 确认 PlayerManager 的 human/dog 不为 null |
| 开关不响应 | `linkedGate` 为 null | 在 PuzzleSwitch Inspector 中拖入对应 Gate |
| 焦虑条不显示 | GameManager UI 引用丢失 | 确认 PlayerSystem 未被意外修改，重新拖入预制体 |
| 屏幕全黑不恢复 | 同上 | 同上 |
| 怪物不动 | `waypoints` 为空数组 | 创建巡逻点并拖入 MonsterPatrol.waypoints |
| 怪物穿墙追击 | `roomCenter` / `roomSize` 未调整 | 设置为怪物所在房间的实际范围 |
| 门不动 | Gate 上无 GateController | 确认使用的是 Gate.prefab 而非手动创建的 Cube |
| 角色穿过地板 | 缺少 Collider 或 Rigidbody | 预制体已含这些组件，确认未误删 |
| 推不动箱子 | 未进入联动模式 | Q 键进入联动模式后再推 |
| LevelExit 无反应 | 对象 Tag 不是 `LevelExit` | 选中 LevelExit，Inspector 顶部设置 Tag |
| 摄像机角度/距离不对 | CameraFollow 参数需调整 | 修改 MainCamera 上 CameraFollow 的 distance 和 angle |

## 10. 加入 Build Settings

若场景需要通过 `SceneManager.LoadScene()` 加载（如关卡间跳转）：

1. `File → Build Settings`
2. 点击 `Add Open Scenes` 将当前场景加入列表
3. 确认场景名与 `GameManager.nextSceneName` 或 `SceneLoader.LoadScene(string)` 传入的名字一致
