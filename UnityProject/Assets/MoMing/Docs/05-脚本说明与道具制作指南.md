# 脚本说明与道具制作指南

## 脚本目录结构

```
Assets/MoMing/Scripts/
├── Core/           # 核心系统
│   ├── GameManager.cs       # 焦虑值管理、UI更新、关卡重置、场景切换
│   ├── PlayerManager.cs     # 角色切换(Tab)、联动模式(Q)、距离判定、脚印可见性
│   ├── CameraFollow.cs      # 俯视角摄像机跟随
│   └── SceneLoader.cs       # UI按钮场景加载
├── Player/         # 角色控制
│   └── PlayerController.cs  # WASD移动、跳跃、E拾取、F开关、狗疾跑
├── Puzzle/         # 机关道具
│   ├── PuzzleSwitch.cs      # F键开关（可设需道具激活）
│   ├── GateController.cs     # 门/栅栏升降
│   ├── PushableBox.cs        # 联动模式可推箱子
│   ├── PickupItem.cs         # 可拾取道具（E键）
│   ├── PressurePlate.cs      # 压力踏板（踩过即永久计入）
│   └── HoldSwitch.cs         # 持续按住F键开关
├── Enemy/          # 敌人
│   └── MonsterPatrol.cs     # 房间限定巡逻+锥形视野+听觉检测
└── Environment/    # 环境
    └── FootprintMarker.cs   # 脚印标记（仅狗可见）
```

---

## 各脚本功能详解

### Core/ — 核心系统

#### GameManager.cs
全局单例 `GameManager.Instance`。管理焦虑值倒计时（分离时 10s 填满）、焦虑条UI更新、普通黑暗遮罩、关键时刻聚光灯遮罩（≥70%时屏幕全黑仅角色周围有光）、关卡重置、通关后场景切换。

| 字段 | 说明 |
|------|------|
| `humanPlayer` / `dogPlayer` | 拖入场景中的 Human / Dog 的 Transform |
| `maxAnxiety` | 焦虑上限(默认100) |
| `anxietyIncreaseRate` | 分离时焦虑增长速率(默认10/s = 10秒倒计时) |
| `anxietyDecreaseRate` | 在一起时焦虑下降速率(默认15/s) |
| `criticalThreshold` | 触发全黑聚光灯的阈值(默认0.7 = 剩余3秒) |
| `spotlightMask` | 拖入 Canvas/SpotlightMask (RawImage) |
| `darknessOverlay` | 拖入 Canvas/DarknessOverlay (Image) |
| `anxietyBarFill` | 拖入 Canvas/AnxietyBarPanel/AnxietyBarFill (Image, Filled类型) |
| `nextSceneName` | 通关后加载的场景名 |
| `levelStartHuman` / `levelStartDog` | 重置时角色回到的位置 |

#### PlayerManager.cs
全局单例。管理 Tab 切换角色、Q 联动模式、Together/Separated 距离判定。角色分离超过 `separationRadius` 时通知 GameManager 开始焦虑倒计时。

| 字段 | 说明 |
|------|------|
| `human` / `dog` | 拖入 Human / Dog 上的 PlayerController 组件 |
| `togetherRadius` | 重聚判定半径(默认3) |
| `separationRadius` | 分离判定半径(默认4.5) |

#### CameraFollow.cs
俯视角摄像机。非联动跟随当前角色，联动模式跟随双人中点。

| 字段 | 说明 |
|------|------|
| `target` | 当前跟随目标（自动管理，初始拖入Human） |
| `height` | 摄像机高度(默认12) |
| `followSpeed` | 跟随平滑速度(默认8) |
| `tiltAngle` | 俯视角度(默认55°) |

#### SceneLoader.cs
供UI按钮调用。`LoadScene(string)` 加载指定场景名。

---

### Player/ — 角色控制

#### PlayerController.cs
挂在 Human 和 Dog 上。处理 WASD 移动、Space 跳跃、E 拾取/丢弃道具(仅人)、F 触发开关(仅人)、狗疾跑(LeftShift)。

| 字段 | 说明 |
|------|------|
| `characterType` | Human 或 Dog |
| `walkSpeed` / `sprintSpeed` | 行走/疾跑速度 |
| `interactRange` | E/F 交互检测半径(默认1.5) |

---

### Puzzle/ — 机关道具（重点）

#### PuzzleSwitch.cs — F键开关
人角色靠近后按 F 激活，激活后联动开门。可设置需持道具才能激活。

| 字段 | 说明 |
|------|------|
| `linkedGate` | 拖入要联动的 GateController 所在物体 |
| `indicatorRenderer` | 拖入开关自身的 Renderer（变色指示） |
| `inactiveMaterial` / `activeMaterial` | 未激活/已激活材质 |
| `requiresItem` | 勾选则需持有道具才能激活 |

#### GateController.cs — 门/栅栏
挂在门物体上。被开关/踏板调用 `Open()` / `Close()`，通过上下位移实现开关门动画。

| 字段 | 说明 |
|------|------|
| `openYOffset` | 开门时向上移动距离(默认5) |
| `moveSpeed` | 升降速度(默认3) |

#### PushableBox.cs — 重型箱子
挂在箱子上。默认锁定(isKinematic)，仅在联动模式(Q)下可推动。

> 无需配置字段，自动监听 PlayerManager 的联动模式状态。

#### PickupItem.cs — 可拾取道具
挂在道具上。人角色按 E 拾取，再按 E 丢弃。拾取后道具跟随角色前方。

> 无需配置字段。自动监听 PlayerController 的 E 键交互。需有 Collider + Rigidbody。

#### PressurePlate.cs — 压力踏板
踩过即永久记录，累计达到 `requiredCount` 个不同对象踩过后永久激活联动门。

| 字段 | 说明 |
|------|------|
| `linkedGate` | 拖入要联动的 GateController |
| `requiredCount` | 需要几个对象踩过(默认2 = 双人踏板) |
| `indicatorRenderer` | 拖入踏板自身的 Renderer |
| `inactiveMaterial` / `activeMaterial` | 未激活/已激活材质 |

#### HoldSwitch.cs — 持续按住开关
人角色站在范围内按住 F 维持激活，松开关闭。可设按住N秒后永久激活。

| 字段 | 说明 |
|------|------|
| `linkedGate` | 拖入要联动的 GateController |
| `permanentAfterHold` | 勾选后按住达到时间则永久激活 |
| `holdTimeRequired` | 需按住秒数(0=一直按住才有效) |
| `indicatorRenderer` | 拖入开关自身的 Renderer |
| `inactiveMaterial` / `activeMaterial` | 未激活/已激活材质 |

> 需有 BoxCollider (isTrigger=true) 作为触发范围。

---

### Enemy/ — 敌人

#### MonsterPatrol.cs — 怪物巡逻
怪物仅在自己房间内巡逻和追击。60°锥形视野 + 4m听觉检测。玩家离开房间后怪物丢失目标。

| 字段 | 说明 |
|------|------|
| `roomCenter` / `roomSize` | 怪物活动房间范围 |
| `waypoints` | 巡逻点数组(拖入空GameObject作为路径点) |
| `detectionRange` | 视野检测距离(默认8) |
| `fieldOfView` | 锥形视野角度(默认60°) |
| `hearingRadius` | 听觉范围(默认4) |
| `catchRadius` | 抓捕距离(默认1.2) |

---

### Environment/ — 环境

#### FootprintMarker.cs — 脚印标记
仅当操作狗时可见的脚印。自动监听 PlayerManager 的角色切换事件。

| 字段 | 说明 |
|------|------|
| `markerRenderer` | 脚印的Renderer(不填则自动获取自身) |
| `visibleByDefault` | 默认是否可见(默认false) |

## 道具制作指南

### 1. F键开关门（最常见机关）

**需要物体：**
- 开关物体（Cube, 缩放0.8×0.3×0.8, 放在地上）
- 门物体（Cube, 缩放0.3×3×4, 堵住通道）

**操作步骤：**
1. 创建开关 Cube，命名为 `R1_Switch1`
2. 给开关添加组件：`PuzzleSwitch`、`AudioSource`、`BoxCollider`
3. 在 Inspector 中：
   - `PuzzleSwitch.linkedGate` → 拖入门物体
   - `PuzzleSwitch.indicatorRenderer` → 拖入开关自身的 MeshRenderer
   - `PuzzleSwitch.inactiveMaterial` → 拖入 Mat_Switch
   - `PuzzleSwitch.activeMaterial` → 拖入 Mat_SwitchActive
4. 创建门 Cube，命名为 `R1_Gate1`
5. 给门添加组件：`GateController`、`AudioSource`
6. 摆放门堵住通道出口

### 2. 压力踏板（双人踩踏板开门）

**需要物体：**
- 踏板物体（Cube, 缩放2×0.1×2, 放在地上, y=0.05）
- 门物体

**操作步骤：**
1. 创建踏板 Cube，命名为 `R1_Plate1`
2. 给踏板添加组件：`PressurePlate`、`AudioSource`、`BoxCollider`(isTrigger=true)
3. 在 Inspector 中：
   - `PressurePlate.linkedGate` → 拖入门物体
   - `PressurePlate.requiredCount` → 设为 2（双人踩）
   - `PressurePlate.indicatorRenderer` → 拖入踏板自身的 MeshRenderer
   - 设置 inactive/active 材质
4. 调整 BoxCollider 尺寸覆盖踏板范围

### 3. 可拾取道具（钥匙等）

**需要物体：**
- 道具物体（Cube/Sphere, 小尺寸, 放在地上）

**操作步骤：**
1. 创建道具，命名为 `R2_Key`
2. 给道具添加组件：`PickupItem`、`AudioSource`、`BoxCollider`、`Rigidbody`
3. 无需额外配置，玩家靠近按 E 自动拾取

### 4. 需道具的开关门（拿着钥匙才能开门）

**操作步骤：**
1. 按"第1节"创建开关和门
2. 在 `PuzzleSwitch` 上勾选 `requiresItem = true`
3. 按"第3节"在场景中放置可拾取道具
4. 玩家需先拾取道具，再靠近开关按 F 才能激活

### 5. 持续按住开关（重型闸阀）

**需要物体：**
- 开关物体 + 门物体

**操作步骤：**
1. 创建开关，添加组件：`HoldSwitch`、`AudioSource`、`BoxCollider`(isTrigger=true)
2. 调整 BoxCollider 范围（比开关大，作为玩家站立区域）
3. 在 Inspector 中：
   - `HoldSwitch.linkedGate` → 拖入门物体
   - `HoldSwitch.holdTimeRequired` → 0=一直按住, >0=按住N秒永久激活
   - `HoldSwitch.permanentAfterHold` → 勾选则按住N秒后永久生效
   - 设置 inactive/active 材质

### 6. 可推箱子（联动模式推动）

**操作步骤：**
1. 创建箱子 Cube，缩放1.5×1×1.5
2. 添加组件：`PushableBox`、`Rigidbody`、`BoxCollider`
3. 无需额外配置，玩家进入联动模式(Q)后自动可推

### 7. 怪物（房间限定巡逻）

**需要物体：**
- 怪物体（Capsule, 放在房间内）
- 巡逻点（空GameObject, 放在房间内几个位置）

**操作步骤：**
1. 创建怪物 Capsule，命名为 `Monster`
2. 添加组件：`MonsterPatrol`、`AudioSource`、`CapsuleCollider`、`Rigidbody`(FreezeRotation)
3. 创建2-4个空GameObject作为巡逻点
4. 在 Inspector 中：
   - `roomCenter` → 房间中心坐标
   - `roomSize` → 房间尺寸
   - `waypoints` → 拖入巡逻点GameObject数组
   - 调整检测参数

### 8. 脚印标记

**操作步骤：**
1. 创建 Quad, 旋转X=90, 缩放0.6×0.6, y=0.02
2. 添加组件：`FootprintMarker`
3. 无需额外配置，操作狗时自动可见

## 通用注意事项

1. **所有需要音效的物体**：添加 `AudioSource` 组件，`AudioClip` 字段暂留空（后续统一替换）
2. **材质颜色**：URP 项目用 `_BaseColor` 而非 `_Color`，已创建的材质 Mat_Switch/Mat_SwitchActive 等可直接拖用
3. **关卡重置**：所有机关脚本都自动监听 `GameManager.OnLevelReset` 事件，重置时自动恢复初始状态
4. **通关触发**：在出口放置一个带 `BoxCollider(isTrigger=true)` 且 tag=`LevelExit` 的物体，玩家碰到即触发 `GameManager.OnLevelComplete()`
5. **UI系统**：使用 `Assets/MoMing/Prefabs/UI_System.prefab` 预制体，拖入场景后只需重新连接 `GameManager.humanPlayer/dogPlayer`、`PlayerManager.human/dog`、`CameraFollow.target` 即可
