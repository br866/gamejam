# Design
1. Render actual formal monster models with their materials and walking poses; inventory active scene assets and interaction mechanisms. Record model identity rather than relying on scene object names.
2. Define acoustic signatures from body mass, foot shape, clothing and attached objects seen in the models. Use separate contact/transient, body and clothing layers where justified, with variations and restrained loudness. Author missing diegetic cues only when grounded in gameplay.
3. Retain native Wwise spatial playback and reusable event references. Bind monster audio to active model identity, preserve dog/UI/music sources and object subtrees. Use selective changes and stable GUIDs.
4. Snapshot current files. Validate engine compilation, active-model coverage, no missing media, event playback and protected hashes. Deliver audition reels, design matrix, measurements, licenses and guarded rollback.
