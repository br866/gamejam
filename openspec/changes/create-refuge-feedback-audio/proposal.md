# Proposal: create-refuge-feedback-audio

## Why

Checkpoint activation and the Level 2 cooperative safe area need a shared
non-mechanical sonic identity. The current pressure-plate sound does not match
the safe area's carpet-and-privacy-screen presentation.

## What Changes

- Create two related one-shot assets with SuperCollider: a lighter safe-area
  activation and a stronger checkpoint activation.
- Use a soft filtered whoosh, restrained high-frequency shimmer, and subtle
  G/D resonance consistent with the project's G-minor musical language.
- Save a reproducible SuperCollider source script alongside the generated-audio
  workflow.
- Do not change Unity or Wwise event routing in this change.

## Impact

- Two new 48 kHz, 24-bit stereo WAV files under Wwise Originals/SFX.
- One new `.scd` source file.
- No scene, script, Work Unit, Event, or SoundBank edits.
